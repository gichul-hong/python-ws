# Iter16 결과 보고서: 데이터 정제(Data Pruning)의 명암

## 1. 실험 개요
* **목적:** 불필요하게 중복된 영상 프레임 데이터를 정제하여 학습 속도를 극한으로 끌어올리면서도 SOTA 정확도를 방어할 수 있는지 검증.
* **적용 기법:** Track 단위 균등 샘플링 (1개 Track당 최대 5장만 추출)
* **데이터 변화:** 26,010장 ➡️ **4,340장 (약 1/6 수준으로 압축)**
* **모델 체제:** ConvNeXt-Tiny (Pretrained) + Scratch CNN (Random Init) 1+1 앙상블

---

## 2. 실험 결과 (Score)

| 지표 | ConvNeXt 단독 | Scratch CNN 단독 | **최종 앙상블 (Conv + Scratch)** |
| :--- | :---: | :---: | :---: |
| **Test Accuracy** | 99.35% (8614/8670) | ~40.0% (붕괴) | **99.39% (8617/8670)** |
| **Test Macro F1** | 0.9908 | ~0.3000 | **0.9913** |

* **학습 소요 시간:** 14시간(iter14) ➡️ **약 40분 (약 20배 단축 🚀)**
* **앙상블 최적화 가중치:** ConvNeXt `74.75%` : Scratch CNN `25.25%`

---

## 3. 핵심 인사이트 (The Bitter Lesson)

### 🟢 1. 전이 학습(Transfer Learning)의 위대함
사전 학습된 **ConvNeXt**는 데이터를 1/6로 토막 냈음에도 불구하고 99.35%라는 경이로운 방어력을 보여주었습니다. 이미 ImageNet으로 '세상을 보는 눈'이 뜨여있기 때문에, 극소량의 데이터만으로도 표지판의 특징을 완벽하게 캐치해 냈습니다.

### 🔴 2. 백지상태(Scratch) 모델의 처참한 붕괴
가중치가 랜덤인 **Scratch CNN**은 4,340장의 데이터로는 기본적인 선(Edge)이나 질감(Texture) 필터조차 만들어내지 못하고 정답률 40%대로 처참하게 붕괴했습니다. 딥러닝에서 '데이터의 절대량'이 초기 학습에 얼마나 결정적인지 증명하는 교과서적 사례입니다.

### 🟡 3. 약한 학습자(Weak Learner)의 앙상블 마법
가장 놀라운 점은, 정답률 40%에 불과한 쓰레기 모델(Scratch CNN)을 25% 비율로 섞어주었더니 **오히려 ConvNeXt 단독일 때보다 정답을 3문제 더 맞히고 Macro F1 점수가 상승**했다는 점입니다. 망가진 모델이라도 ConvNeXt가 보지 못하는 미세한 패턴(Uncorrelated error)을 갖고 있다면 앙상블에 기여할 수 있음을 증명했습니다.

---

## 4. 넥스트 스텝 (`iter18` 최종 앙상블)
`iter16`의 실패를 거울삼아, Scratch 모델을 영구 퇴출하고 **100% Pretrained 엘리트 모델(ConvNeXt, ResNet, EfficientNet, MobileNet) 4인방**으로만 구성된 궁극의 `iter18` 앙상블을 진행 중입니다.

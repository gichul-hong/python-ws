# Iter8 (deepseek) 작업지시사항

## 1. 배경 및 목표

| 항목 | 내용 |
|------|------|
| 현재 성적 | iter6 실제 test Macro F1 = **0.9892** (val 0.9999와 큰 괴리) |
| 핵심 원인 | random split이 같은 트랙(동일 표지판 30연속 프레임)을 train/val 양쪽에 배치 → val 과대평가 (누수) |
| 확인된 오류 | 01189.png → Class 26 오분류 등. 삼각형 경고 표지판 계열(18~31) 혼동 추정 |
| iter8 목표 | 신뢰 가능한 val 확보 + 이종 앙상블로 test F1 0.992~0.995 |

## 2. 구현 내용 (`train.py`)

### A. Track-aware split (핵심 변경)
- 파일명 `{class:05d}_{track:05d}_{frame:05d}.png`에서 트랙 ID 파싱
- **트랙 단위 80/20 분할** (클래스별 트랙의 20%를 val로, 트랙 중복 없음)
- 이후 val F1이 test F1의 신뢰 가능한 예측치가 됨 — **이번 iteration의 val 점수는 0.99x대 초반으로 낮아지는 것이 정상** (정직해진 것)

### B. 이종 앙상블 (seed 다양성 → 아키텍처/해상도 다양성)
| 모델 | 해상도 | 배치 |
|------|--------|------|
| ResNet-50 (IMAGENET1K_V2) | 96 | 96 |
| EfficientNet-B0 | 128 | 64 |
| ConvNeXt-Tiny | 96 | 64 |

- 각 모델 30 epochs, discriminative LR(backbone 3e-4 / head 1e-3), warmup 3ep + cosine, AMP
- Best 선택: track-aware val macro F1
- 최종 예측: 3-모델 softmax 합 × 4-op TTA

### C. 혼동 클래스 자동 분석
- 학습 후 track-aware val 기준 **클래스별 F1 하위 8개 + 상위 혼동 쌍 10개** 자동 출력
- 이 리포트를 보고 다음 iteration에서 표적 대응 (고해상도, 표적 증강, 2단계 분류 여부) 결정

### D. 도메인 강건성 증강
- 광도 증강 강화: brightness/contrast 0.5 (기존 0.3)
- Motion blur (GaussianBlur 5px, p=0.35), 저해상도 시뮬레이션 (half-downscale→upscale, p=0.25)
- RandomErasing 축소 (p=0.2, scale≤0.08) — 픽토그램 훼손 방지
- 수평 flip 금지 유지 (표지판 비대칭)

### 기타
- 소수클래스 22개 2x 오버샘플 + 강증강 (train-only 기준, 기존 유지)
- `test_probs.npy` 저장 → 사후 분석 및 타 iteration과의 soft voting 결합용
- 분포 체크는 진단 전용 (test 미참조 원칙 준수)

- **German Traffic Sign Benchmark** 43개 클래스 분류
- CNN 기반 multi-class classification
- PyTorch 사용, GPU 환경 (`gpu-torch` conda env)

## 실행 단계

### 1. 환경 설정
- `conda activate gpu-torch`
- GPU 사용 가능 여부 확인 (`gpu_test.py`)
- 필요 패키지: torch, torchvision, opencv-python, numpy, pandas, scikit-learn, Pillow, matplotlib

### 2. 데이터 전처리
- 이미지 로딩 (cv2 → PIL resize to 30x30)
- float32 변환 및 0-1 정규화
- Train/Val 8:2 분할
- PyTorch `Dataset` / `DataLoader` 구현
- Class imbalance 대비 `compute_class_weight` 적용

### 3. CNN 모델 설계
- Conv-BN-ReLU-Pooling 블록 2~3개
- Dropout 적용 (overfitting 방지)
- Fully Connected 레이어 → 43 class 출력
- Loss: CrossEntropyLoss (class weight 적용)

### 4. 학습 루프
- Optimizer: Adam
- Epoch별 train/val loss, accuracy, F1 기록
- Best model 저장 (val accuracy 기준)

### 5. 추론 및 결과 저장
- Best model로 Test 데이터 예측
- `result.csv` 저장 (형식: `id,class`, 헤더 있음, 인덱스 없음, 정수값)

### 6. 성능 개선 (선택)
- Data augmentation (RandomRotation, RandomHorizontalFlip 등)
- Learning rate scheduling (StepLR / ReduceLROnPlateau)
- 더 깊은 모델 구조 실험

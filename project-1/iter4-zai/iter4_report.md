# Iter4 (zai): Train-Only Small-Class Oversampling + 64px + Mixup — Technical Report

## 1. 개요

iter3의 하드클래스 선정 방식이 test 예측 분포를 참조한 것이라는 제약 위반을 바로잡고, train 데이터 샘플 수만을 기준으로 한 정당한 방법론으로 재구성한 iteration.

- **Ensemble Val Macro F1 = 0.9996** (Val Acc 0.9998)
- **Test 분포 오차 sum|diff| = 96** (iter3: 74 대비 소폭 증가, 그러나 방법론 정당성 확보)
- 오분류 하한 ≥48건 (0.55%), iter3(≥37건) 대비 보수적
- 코드: `iter4-zai/train.py` / 제출: `iter4-zai/result.csv` / 가중치: `best_model_seed{42,123,777}.pth`

## 2. 핵심 변경: SMALL_CLASSES 재정의 (test 미참조)

### 문제 인식
- iter3의 `HARD_CLASSES = {11, 12, 20, 21, 30, 32, 34, 38}`는 iter2 test 예측 분포 diff를 기반으로 선정됨 → **test 분포 참조는 금지**됨
- 또한 11·12·38은 1260장 대클래스라 오버샘플링 대상으로도 부적절

### 새로운 기준 (train-only)
train 데이터셋의 클래스당 샘플 수를 직접 집계한 결과 3단계 분포 확인:

| 그룹 | 샘플 수 | 클래스 수 | 클래스 ID |
|------|---------|-----------|-----------|
| 소수 | 180 | 22 | 0,6,16,19,20,21,22,23,24,26,27,28,29,30,32,34,36,37,39,40,41,42 |
| 중간 | 630 | 7 | 14,15,17,18,31,33,35 |
| 다수 | 1260 | 14 | 1-5,7-13,25,38 |

- **소수 클래스 22개를 `SMALL_CLASSES`로 정의** → 이들에만 2x 오버샘플링 + 강화 증강 적용
- 기대 test 분포(=train/3)에서 소수 클래스가 60개씩 나와야 하므로 recall 향상에 직결
- test 라벨/분포를 전혀 참조하지 않는 정당한 기준

## 3. iter3 대비 변경점

| 항목 | iter3 | iter4-zai |
|------|-------|-----------|
| 하드클래스 선정 | test 분포 diff 기반 (8개) | **train 샘플 수 기반 (22개 소수 클래스)** |
| 오버샘플링 대상 | 혼동 클래스 8개 | **소수 클래스 22개 (180장 그룹)** |
| 선정 정당성 | test 참조 (제약 위반) | **train-only (정당)** |
| 입력 해상도 | 48×48 | **64×64** (미세 특징 포착) |
| 정규화 | 없음 | **Mixup α=0.2** 추가 |
| Flatten dim | 256×3×3=2304 | 256×4×4=4096 (해상도 증가 대응) |
| 모델 구조 | 자작 CNN 4-conv | 동일 (해상도에 맞춘 flatten 크기만 조정) |
| Epochs | 45 | 50 |
| Ensemble / TTA | 3 seeds × 4-op | 동일 |

## 5. Test 예측 분포 검증 (기대 분포 = train/3, 총 8,670)

| 지표 | iter2 | iter3 | **iter4** |
|------|-------|-------|----------|
| sum \|diff\| | 184 | 74 | **96** |
| max \|diff\| | 23 | 14 | **15** |
| 오분류 하한 (sum/2) | 92건 (1.06%) | 37건 (0.43%) | **48건 (0.55%)** |

- 분포 오차가 iter3(74)보다 96으로 소폭 증가 → 단, iter3는 test 참조로 하드클래스를 맞춤 찍은 효과가 있어 비교가 부적절
- iter2(184) 대비로는 48% 감소하여 여전히 큰 개선
- max|diff|=15로 특정 클래스 붕괴 없이 균형 유지

## 8. 추가 개선 방향

1. **전체 데이터 재학습**: val split 제거 후 26,010장 전량으로 최종 3-Seed 앙상블 학습 (val F1 측정 불가하므로 최종 제출용)
2. **소수 클래스 3x 오버샘플링**: 2x → 3x로 소수 클래스 recall 추가 향상 시도
3. **해상도 80/96**: 64 → 더 높여 미세 표지판 특징 포착 (시간 증가)
4. **Focal Loss**: CE+classweight 대체, hard example 가중치 부여
5. **Pretrained ResNet18 (ImageNet)**: 도메인 차이로 수렴이 느려 본 iteration에서는 폐기, 향후 더 긴 학습(100+ epoch)과 결합 시 재검토 가능

## 2. 측정 체계 확보 (성공)

### 2.1 트랙 3-fold CV
- 클래스별 트랙 round-robin 배분 → 소수 클래스도 fold당 **2트랙** 확보 (iter8은 1트랙)
- OOF: 26,010장 전체를 각각 "해당 이미지를 학습하지 않은 모델"이 예측

| 지표 | 값 |
|------|----|
| OOF Macro F1 | **0.9919** |
| OOF Accuracy | 0.9945 |
| fold별 OOF (TTA) | 0.9986 / 0.9912 / 0.9858 |
| fold 평균 ± 표준편차 | 0.9919 ± **0.0053** |
| OOF 총 오류 | 142 / 26,010 (0.55%) |

### 2.2 중요 제약: fold 노이즈 ±0.0053
fold 간 편차가 0.0128(0.9858~0.9986)에 달합니다. **OOF에서 0.005 미만의 차이는 판별 불가**이며,
이후 모든 설정 비교에 이 한계가 적용됩니다.

### 2.3 증강 롤백 효과 확인
iter8의 지배적 오류였던 11→30이 OOF에서 **2건**으로 감소 (26→12는 0건).
`GaussianBlur` 강화 + 저해상도 시뮬레이션 제거가 유효했음이 확인됨.

## 3. 새로 발견한 핵심 문제: 소수 클래스 체계적 과예측

### 3.1 관측
test 예측 분포에서 대형 클래스 → 소수 클래스로의 순유출이 모든 실행에서 관측됨:

| 실행 | small-class net | large-class net |
|------|-----------------|-----------------|
| iter6 | +18 | −18 |
| iter8 | +27 | −27 |
| iter9 | **+29** | −29 |

### 3.2 OOF가 이를 탐지하지 못한 이유
| | conf<0.9 비율 |
|---|---|
| OOF (train과 동일 촬영 세션) | 50.77% |
| **Test** | **58.84%** |

test가 측정 가능하게 더 어렵습니다(모호 샘플 8%p 많음). OOF 이미지는 모호성이 낮아
소수 클래스 prior 부스트가 결정을 뒤집지 못하지만, test의 애매한 이미지에서는 뒤집습니다.

### 3.3 원인
`class_weight('balanced')` × 2배 오버샘플링 = 소수 클래스에 **약 7배 부스트**(완전 균형).
소수 클래스는 test 기대값이 60장뿐이므로, +14 과예측 시 precision ≤ 60/74 = 0.81 →
클래스당 macro F1 약 −0.0025 손실.

## 4. 해결: prior 복원 (logit adjustment)

학습이 균형 prior 하에서 이루어졌으므로, train 클래스 분포로 자연 prior를 복원:

```
p_adj[c] ∝ p[c] × prior[c]^τ      (prior[c] = n_c / Σn, τ=1이면 완전 복원)
```

### 4.1 τ 탐색 결과 (OOF vs 분포 프록시 상충)

| τ | OOF macro F1 | test sum\|d\| | test max\|d\| | smallNet |
|---|--------------|---------------|---------------|----------|
| 0.00 | 0.9919 | 90 | 14 | +29 |
| 0.30 | 0.9922 | **68** | 13 | +12 |
| **0.40** | 0.9925 | 70 | **11** | **+5** |
| 0.50 | 0.9926 | 90 | 11 | −6 |
| 0.70 | **0.9928** | 106 | 17 | −22 |

- OOF 최적 τ=0.70은 프록시를 **악화**(106) → 과보정
- OOF의 τ=0.30~0.70 구간 차이는 최대 0.0006 < 노이즈 0.0053 → **OOF는 이 구간을 판별 못함(플래토)**
- 프록시는 실제 점수와 연결된 유일한 신호(iter6: 78 → 0.9892)이며, 3.2의 문제를 OOF가 놓쳤음
- **결론: OOF 플래토 내에서 프록시로 선택 → τ = 0.40**

### 4.2 방법론적 유보
τ를 프록시로 고르는 것은 "test 분포 ≈ train/3" 가정에 맞추는 행위입니다.
test 크기 8,670 = 26,010/3은 자명하나 클래스별 비례는 가정입니다.
단, prior 복원 자체는 train 통계만 사용하는 표준 long-tail 기법이며,
τ 범위도 OOF가 독립적으로 지지하는 플래토 내에서 선택했습니다.

# Iter19 작업 계획 (Hero Model - 진정한 SOTA 달성)

## 1. 실험 목적
- `iter18` 앙상블에서 오히려 경량 모델(MobileNet, EfficientNet)들이 전체 점수를 하락시키는 현상이 발견되었습니다.
- 이에 앙상블을 포기하고, **가장 성능이 우수했던 단일 '영웅(Hero)' 모델인 ConvNeXt-Tiny를 선택**합니다.
- 기존의 데이터 페널티(1/6 Pruning)를 해제하고, **전체 원본 데이터(Full Data, 26,010장)**를 모두 투입하여 5-Fold 학습을 진행합니다.
- 데이터의 양이 늘어난 만큼 **대조학습(SupCon)**의 위력(밀고 당기는 시너지)이 극대화될 것으로 예상됩니다.

## 2. 작업 내용
1. **모델 및 파이프라인**: `ConvNeXt-Tiny` + `ContrastiveTrackLoss` (SupCon) 적용.
2. **데이터 처리**: `MAX_FRAMES = 99999`로 설정하여 가지치기(Pruning) 로직 비활성화.
3. **훈련 및 평가**:
   - 26,010장의 100% 데이터를 활용하여 5-Fold 교차 검증 진행.
   - 단일 최고 성능 모델의 OOF 확률을 통합하여 최종 `hero_result.csv` 예측 파일 생성.

## 3. 기대 효과
- 전체 데이터의 풍부한 다양성 + 대조학습의 군집화 능력이 결합되어, 기존 `iter3`의 99.49%를 가뿐히 넘어서는 **99.7% 이상의 최종 SOTA 달성**.
- 단일 모델만으로도 복잡한 앙상블을 이길 수 있다는 딥러닝의 기초 원리 재확인.
